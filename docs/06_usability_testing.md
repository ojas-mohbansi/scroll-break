# Usability Testing Tasks, Protocol & Results

## Testing Overview & Methodology
Usability evaluation of the **ScrollBrake** prototype was conducted with **6 consenting participants** (ages 20–26). Testing focused on observing task completion, identifying points of confusion, measuring task success rates, and collecting feedback on the mindful intervention experience.

To ensure ethical data practices, **no personal app usage logs, private text input, or background screen data were collected or stored**.

---

## Assigned Usability Tasks

### Task 1: Enable Scroll Velocity Intervention for Social Apps
- **Scenario:** You want to prevent absentminded doomscrolling on Instagram and TikTok without completely locking yourself out of the apps.
- **Goal:** Enable ScrollBrake intervention monitoring for target social apps from the Blocker Control screen.

### Task 2: Navigate a Mindful Interruption & Set a Session Intention
- **Scenario:** You open Instagram and start flinging through reels. A ScrollBrake speed bump overlay appears.
- **Goal:** Complete the 5-second breathing pause, type a valid session intention (e.g. *"Check recipe video"*), set a 5-minute limit, and resume usage.

### Task 3: Configure a Study Focus Session with Planned Breaks
- **Scenario:** You have a 1-hour study block for an upcoming exam and want to prevent mobile distractions.
- **Goal:** Create a 25-minute study focus session with a 5-minute planned break in Focus Mode.

## Key Points of Confusion & Qualitative Feedback

1. **Timer Readiness Signal:** Participants initially tried tapping the "Continue Mindfully" button before the 5-second breathing timer reached 0. (Feedback: Button needs a clear visual disabled/countdown state until timer completes).
2. **Accessibility Permission Clarity:** First-time users were unsure why Accessibility Service permission was requested. (Feedback: Add a clear explanatory screen before system settings dialog).
3. **Focus Mode Toggle:** Users were unsure about the difference between "Mindful Speed Bump" mode and "Hard Lockout" mode during focus sessions. (Feedback: Add helper tooltips explaining each mode).
